# media-center-on-PC-with-no-screen-with-controller-on-android-tablet

Follow the intructions on the latest release [here](https://github.com/cloudyhair6/media-center-on-PC-with-no-screen-with-controller-on-android-tablet/releases/latest) or just download the latest installer\_and\_updater.py [here](https://github.com/cloudyhair6/media-center-on-PC-with-no-screen-with-controller-on-android-tablet/releases/latest/download/installer_and_updater.py)

## Required:

* Windows 11 - [https://www.microsoft.com/en-gb/windows/get-windows-11](https://www.microsoft.com/en-gb/windows/get-windows-11) - [https://www.microsoft.com/en-us/software-download/windows11](https://www.microsoft.com/en-us/software-download/windows11)
* Surround sound setup of 5.1 on a HDMI port on your GPU that is not **NVIDIA**!
* Equalizer APO on your GPU (There is a really big issue with **NVIDIA** GPUs so don't use GPUs from **NVIDIA**) - [https://equalizerapo.com/download](https://equalizerapo.com/download) - [https://onboardcloud.dl.sourceforge.net/project/equalizerapo/1.4.2/EqualizerAPO-x64-1.4.2.exe?viasf=1](https://onboardcloud.dl.sourceforge.net/project/equalizerapo/1.4.2/EqualizerAPO-x64-1.4.2.exe?viasf=1)
* Spotify not from the microsoft store directly - [spotify.com/download](https://spotify.com/download) click Download directly from Spotify ignore the big download from the microsoft store button - [https://download.scdn.co/SpotifySetup.exe](https://download.scdn.co/SpotifySetup.exe),
* Python 3.12 - [https://www.python.org/downloads/release/python-31210/](https://www.python.org/downloads/release/python-31210/) - [https://www.python.org/ftp/python/3.12.10/python-3.12.10-amd64.exe](https://www.python.org/ftp/python/3.12.10/python-3.12.10-amd64.exe)
You will need the apk from the tablet\_apk folder currently only supporting android 2.3.4 on an amazon fire kindle first generation model.
* A hard drive full of music.
BTW: This is generated by Google antigravity (everything but this file) it did a good job at it and it has got most of the bugs out of it, some may remain like light mode or native on the tablet.

any bugs please report in the [issues](https://github.com/cloudyhair6/media-center-on-PC-with-no-screen-with-controller-on-android-tablet/issues/new).
